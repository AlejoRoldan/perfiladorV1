# Referencia de diseño frontend — Impeccable

La migración del Perfilador UCorp toma como referencia el repositorio público **Impeccable**, orientado a guiar agentes de desarrollo en diseño frontend mediante una habilidad, comandos de trabajo, iteración visual en navegador y reglas de detección. [1]

## Pautas aplicables a Itti Talent Compass

| Principio de referencia | Aplicación al proyecto |
|---|---|
| Diseñar e iterar con evidencia visual. | Mantener capturas de escritorio y móvil para cada flujo relevante del Perfilador F1. |
| Evitar interfaces genéricas. | Conservar la identidad de Talento: barra lateral oscura, acento verde de señal, jerarquía editorial y visualizaciones orientadas a conversación humana. |
| Mantener estados de interacción claros. | Mostrar explícitamente borrador, generación degradada, revisión, aprobación, activa y enviada en las HUs H2–H8. |
| Validar accesibilidad durante la implementación. | Preservar navegación por teclado, foco visible, tablas alternativas para gráficos y auditoría Axe. |
| Preferir composición y reutilización. | Mantener separados dominio, motor de reglas, vistas, estilos y contrato OpenAPI. |

> Esta referencia orienta decisiones de experiencia y calidad visual. No se incorpora código, logotipos ni dependencias de Impeccable al producto sin una evaluación específica.
