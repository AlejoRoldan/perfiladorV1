# Resumen del modelo de perfilamiento

**Fuente:** documento proporcionado por Alejo: `ModelodePerfilamiento-ResumenEjecutivo.docx`.

## Reglas de cálculo funcional

Todas las respuestas se traducen a una escala común de **1 a 4**. Las preguntas tienen pesos distintos por tipo —un escenario práctico complejo pondera más que una pregunta de verdadero/falso— y las competencias también se ponderan de acuerdo con el cargo o seniority.

El diagnóstico compara el nivel real con el nivel esperado. Se aplica una tolerancia del **3 %** para evitar clasificar como brecha a diferencias mínimas. El documento describe tres estados por competencia:

| Estado | Criterio funcional | Orientación para Talento |
|---|---|---|
| Brecha crítica | Nivel real inferior al esperado después de considerar la tolerancia. | Priorizar conversación y plan de desarrollo. |
| Nivel aceptable | Cumple el esperado o queda levemente por debajo dentro de la tolerancia. | Sin acción inmediata. |
| Talento destacado | Supera de forma clara el nivel esperado. | Identificar como posible mentor o como señal para conversación de crecimiento. |

## Implicancias para la demo

La pantalla de diagnóstico debe mostrar por cada competencia el nivel real, el esperado, la diferencia y el estado en lenguaje comprensible. Los gráficos de semáforo deben usar las tres categorías anteriores, sin convertir el resultado en una decisión automática. Los pesos por pregunta y seniority deben ser visibles o explicables en el cálculo de la evaluación.

## Límites que deben respetarse

El documento propone enrutamiento hacia capacitación y una futura mirada de líder como oportunidades de mejora, no como capacidades actuales. La demo debe limitarse a diagnóstico y orientación para revisión humana; no debe asignar automáticamente cursos, promociones ni sanciones.
